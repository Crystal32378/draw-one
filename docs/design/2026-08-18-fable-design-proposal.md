# Draw One 設計提案 — 一張籤詩紙，放進手機

**作者：** 飛寶（Claude Fable 5）
**日期：** 2026-08-18
**性質：** 獨立設計判斷。不是對蝦蝦第二輪方案的回應，也不是實作規格；是我讀完產品文件、production truth layer、現有 UI 之後，自己會怎麼做的完整提案。
**硬約束（不可協商）：** 真形式不包假內容／回應主體不得是神明或 AI oracle／一事一籤／原典與生成解讀不可混成同一種 authority。

---

## 0. 核心命題：設計對象是那張紙，不是那間廟

所有方向性的爭論——美術館 vs 夜市、高冷 vs 土氣、儀式 vs 表演——我認為都源自同一個未回答的問題：**這個產品的「物」是什麼？**

我的答案：是**籤詩紙**。

在真實的求籤裡，籤筒、籤枝、擲筊都是過程；最後留在你手上、被摺起來放進皮夾、幾年後在錢包夾層裡再被翻到的，是那張紙。它便宜、量產、薄、直排、木刻字、印著廟名——但它是整個儀式裡唯一**屬於你**的東西。它同時是：

- **日常的**（不是文物，是隨手可得的印刷品）——這是「地氣」；
- **講究的**（籤號、詩文、版式、廟名，每個位置都有規矩）——這是「優雅」；
- **私人的**（它承載的是你的問題，不是廟的權威）——這是 user autonomy。

籤詩紙天然就站在 Crystal 要的那個位置上：不在美術館的玻璃櫃裡，也不在夜市的攤位上，而是在一個普通人的皮夾裡。**把這張紙誠實地放進手機，就是整個設計。** 介面不是「儀式空間」，介面是這張紙落下來的那張桌面。

這個命題同時自動解決三個懸而未決的辯論：

1. **Provenance 怎麼顯示？** 真實籤詩紙本來就印著廟名——「艋舺龍山寺」印在紙頭是這個物件的原生形式。出處不是博物館標籤，是**版記（colophon）**。文化原生的 provenance 展示，不借權威、不藏資訊。
2. **暗色還是亮色？** 紙是亮的。下詳（§4）。
3. **Reveal 要幾拍？** 真實的紙不分拍揭曉——你拿到的是一整張。下詳（§6）。

## 1. Design Language

> **「一張從台灣廟埕走出來的籤詩紙，被安靜、精準地放在今天的手機螢幕上。桌面是紙，文字是墨，唯一的紅是印泥。你寫下問題，親手抽出它，然後把它收進自己的籤簿。」**

三條操作原則：

- **物 > 介面。** 螢幕上只有兩種東西：那張紙（原典層），和桌面（其他一切）。任何元件先問「這在紙上，還是在桌上？」——籤詩、籤號、版記在紙上；按鈕、解讀、你的筆記、導覽在桌上。紙上的東西來自 corpus，一個字都不能是生成的；桌上的東西是產品文案，永遠不穿紙的形式。**這就是「原典與解讀不可混 authority」的視覺化。**
- **重量放在使用者手上，不放在系統嘴上。** 儀式感全部來自使用者的動作（寫、按、抽、收），系統的回應零懸念、零人格、零延遲表演。
- **地氣＝日常，不＝裝飾。** 不加雲紋、不加龍鳳、不加毛筆飛白。台灣的地氣是白日的、印刷的、生活的：籤詩紙、鑄字行的鉛字、藥籤袋、日曆紙。優雅來自版式的準確，不來自風格的堆疊。

## 2. Mobile Flow — 五個狀態，不是一頁長捲

現有 prototype 是 desktop 版面斷點堆疊；我的版本是手機原生的狀態機，每個狀態一件事：

```
① 問 (Ask)        ② 選籤系 (Choose)     ③ 抽 (Draw)        ④ 紙 (Slip)        ⑤ 籤簿 (Book)
寫下你的問題    →  選一套籤詩文本    →  長按抽出籤枝    →  收到籤詩紙      →  收進籤簿＋自己的筆記
```

**① 問——問題是第一個畫面，不是神明。**
開屏就是一行提示＋輸入框＋鍵盤。理由：這個產品真正的價值機制是「把混亂的心事寫成一句具體的問題」，articulation 本身就是療癒的一半。神明卡片放在第一屏（現狀）等於說「先選權威，再想問題」；反過來才對。例句改為 reflective 而非決策委託：「我在這段關係裡真正害怕的是什麼」而不是「我該不該分手」。保留現有那句好文案：「抽籤不是預言未來，而是幫你重新看見自己的內心與處境。」

**② 選籤系——選的是文本傳統，不是神明。**
三個選項以**籤系名稱**為主體、神明為脈絡：

- 六十甲子籤（北港朝天宮）
- 觀世音靈籤（艋舺龍山寺・百首）
- 江東王靈籤（道藏本・關帝）

純文字排版＋各籤系的紙色（§4），**沒有 emoji**。把選擇框成「你要從哪一套傳承文本裡抽」，而不是「你要向哪位神明請示」——這是 attribution guardrail 在資訊架構層的實作，也順帶讓「三套 corpus」的研究工作直接成為產品的可感價值。

**③ 抽——勞動是真的，等待是假的，所以只留勞動。**
螢幕下方一個籤筒的剪影（線描，不擬真）。**長按並上滑**：一支籤枝隨著你的按壓緩緩升起，鬆手即落回；拉到頂端才算抽出，伴一次觸覺回饋。抽出瞬間紙就來——**沒有 1.2 秒延遲，沒有 loading 文案**。使用者付出了真實的兩秒鐘專注與動作，系統不需要再表演思考。這是對「勞動幻覺」的正面替代：把假的系統勞動換成真的使用者勞動。

**④ 紙——見 §6。**

**⑤ 籤簿——歷史記錄的文化原生形態。**
過去的籤以「籤簿」呈現：日期、你的問題、那張紙、你當時寫下的話。它不是收藏匣，是**對照工具**——幾週後回看「當時我在怕什麼、籤怎麼說、後來呢」，是全產品最反迷信的機制。一事一籤的呈現也在這裡自然解決：同一個問題再問一次，不彈出錯誤訊息，而是**直接翻開籤簿到那一頁**——「這個問題，你已經有一支籤了。」規則變成導覽行為，不是懲罰文案。

## 3. 籤詩 Reveal — 兩拍，而且每一拍都是使用者的動作

三拍自動揭曉（動畫→全屏詩→停頓→解讀）會把 reveal 做成系統的演出。真實流程只有兩個交接動作，兩拍都由使用者觸發：

- **第一拍：籤枝。** 抽出的籤枝橫在螢幕上，只有籤號（「第三十九籤」／六十甲子則是「壬午」）。這對應真實世界「你先拿到一支寫著號碼的竹枝」。
- **第二拍：換紙。** 點籤枝（對應「拿號碼去籤詩櫃換紙」），籤詩紙從上方滑落到桌面。**一整張、一次到位**：籤號、詩文、版記同時在紙上。紙不分拍——分拍揭曉是舞台劇，整張抵達是收到一份文件。

拍與拍之間零自動延遲。節奏感來自使用者自己的手速：想慢慢來的人自然會停在籤枝那裡看一眼。

## 4. Material / Texture / Color

**亮色。這是我對現狀（以及「夜間籤房」方向）唯一的根本翻案。**

籤詩在生活裡是白天的、日常的、拿在手上的紙。暗色介面把抽籤框成降神會——氛圍越好，越接近 mystical AI；而紙色介面把抽籤框成**讀一份文本**。宣紙質感物理上也只存在於亮面——深色的紙讀起來是漆器或皮革，不是紙。夜間變體可以日後作為情境選項，但 design language 的本體是紙。

| 角色 | 色 | 用法 |
|---|---|---|
| 桌面 | 暖灰米 `#EDE8DC` 帶極低對比紙紋 | 全域底色，noise ≤ 3% 對比 |
| 籤詩紙 | 各籤系紙色（見下） | 唯一的「物」 |
| 墨 | `#26221C` | 所有正文；純黑禁用 |
| 淡墨 | `#6E6759` | 次要文字、版記 |
| 硃砂 | `#A63A2B` | **全 app 唯一彩色**：印章、抽籤動作的 active 態、籤簿裡未讀筆記的小點。覆蓋率 < 5% |

**籤系紙色——差異化的文化原生解。** 台灣廟裡的籤詩紙本來就有紙色傳統（北港六十甲子籤常見粉紙，觀音籤常見黃紙）。三套 corpus 用三種淡紙色區分：六十甲子＝淡粉 `#F5E6E0`、觀世音＝藤黃 `#F4ECD4`、江東王＝月白 `#EFF0E8`。這取代 emoji 的功能（快速辨識），而依據是真實印刷傳統，不是 vibe 標籤。（此為 presentation 選擇，具體色票需對照實物照片校準——列入 open questions。）

**質感規則：** 紙紋只出現在紙上；紙有極細的邊框雙線（木刻版框的素直形式，不用回紋）；陰影一律 1–2px 的接觸影，不做浮起卡片；**零圓角**——紙是裁的，不是磨的。這一條同時把 dark SaaS / Bento 語彙整套排除。

## 5. Typography

**直排是這個產品的簽名，但只有原典有資格直排。**

- **籤詩本文：** 思源宋體（Noto Serif TC）SemiBold，`writing-mode: vertical-rl`，右起直排，一句一行。字級是全 app 最大（手機上約 30–34px），**詩比任何標題都大**——這個 app 沒有行銷 H1，最大的字永遠是原典。七言四句在手機高度剛好成四柱，這不是巧合，是籤詩紙比例本來就是為這個文體設計的。
- **籤號：** 直排大字或紙右上角，用中文數字（「第三十九籤」），對齊木刻傳統；六十甲子的干支（甲子、壬午）是比數字更古老的編號層，優先呈現。
- **版記（provenance）：** 紙的左緣或紙尾，直排小字淡墨：「艋舺龍山寺《觀世音靈籤》百首・轉錄狀態：已對勘」。PROBABLE 誠實寫「單一來源轉錄・待複核」——用人話，不用英文枚舉值。位置與字級表明它是版本資訊，不是權威徽章。
- **UI 文字：** 橫排、系統黑體（PingFang TC / 思源黑體）、Regular、小而安靜。UI 永遠不用宋體——宋體是紙的字，黑體是桌面的字，**字體本身就是 authority 分層**。
- **未來的 AI 解讀（管線建成後）：** 橫排、黑體、在桌面上（永不上紙）、標題固定為「一種解讀」＋生成標示。連字體都和原典不同科，使用者不需要讀任何說明就能感覺到「這是另一件東西」。

## 6. 原典／出處／解讀的分層 = 紙上／紙緣／桌上

| 層 | 位置 | 字體 | 內容來源 | Authority |
|---|---|---|---|---|
| 原典 | 紙上 | 宋體直排 | corpus 逐字，fail-closed | 歷史文本自身 |
| 出處 | 紙緣（版記） | 宋體直排小字淡墨 | provenance metadata | 版本事實 |
| 你的話 | 桌上（籤簿） | 黑體橫排 | 使用者輸入 | 使用者自己 |
| 解讀（未來） | 桌上，opt-in 展開 | 黑體橫排＋生成標示 | governed pipeline + voice lint | 明示為「一種解讀」 |

v1 沒有 AI 解讀，那個位置給**使用者自己的筆記欄**：「寫下你此刻想到的」。自我詮釋先於機器詮釋——這既是 autonomy 的立場宣示，也讓籤簿的回訪對照有內容可看。

## 7. 現有元素的去留

**保留：** 宋體用於中文正文的直覺（升級為全面的紙／桌字體制度）；「抽籤不是預言未來」文案；克制的線條與低裝飾密度；印章元素（從 masthead 的品牌章改為紙上的籤系章，硃砂色）；一事一籤與 truth layer 全部邏輯。

**捨棄：** 暗色主題（→ 紙色）；emoji 神明（→ 籤系紙色＋文字）；「Eastern Oracle System / Ritual UI」英文 eyebrow（自我東方主義的標籤，產品不需要向誰解釋自己是東方的）；行銷側欄（Product Vision / Future Features 移到 About）；1.2 秒延遲（→ 使用者長按的真實勞動）；decision-delegation 例句（→ reflective 例句）；桌機優先版面（→ 手機狀態機，桌機是紙放大置中的劇場模式）。

## 8. 與蝦蝦方向的主要分歧（供決策，不是要求站隊）

1. **紙色 vs 夜間籤房。** 她保留暗色地基，我翻案為亮色紙面。這是兩個成立的美學方向，但只有一個能承載「宣紙質感」與「白日日常」的地氣定位。
2. **Reveal：三拍系統演出 vs 兩拍使用者交接。** 她的節奏來自系統的編排（動畫、停頓），我的節奏來自使用者的動作（長按、點取）。
3. **出處：museum label vs 版記。** 同樣是小字出處，隱喻不同——博物館標籤說「這是展品」，版記說「這是這一版的紙」。後者是籤詩紙自己的傳統。
4. **等待拍。** 她列為應保留的骨架，我已在 truth layer 移除文案、並在本提案移除延遲本身。

## 9. Open Questions（需要 Crystal 或後續研究）

1. 三套籤系的實體籤詩紙照片（北港、艋舺）——紙色、版框、廟名位置的實物校準。蝦蝦的 corpus 研究資料裡可能已有。
2. 六十甲子籤是否以干支為主要籤名（壬午）而數字為輔？建議是，待與北港實物對照。
3. 直排在日/韓/英多語版的策略（英文無直排傳統——翻譯版的紙是否橫排、如何保持物件感）。
4. 籤簿是否需要跨裝置（帳號）——目前 localStorage 綁定單一瀏覽器。
5. 深夜情境變體（暗桌面＋紙仍是亮的——紙在檯燈下）是否值得做。

## 10. 一句話收尾

> 不做「高級東方風」，做**一張真的紙**。它印著真的字、記著真的出處、承載你真的問題——而手機，只是它這個時代落腳的桌面。
