# The Arrival — ink pass（入廟體驗與視覺升級提案 v1）

**日期：** 2026-11-14　**作者：** 飛寶（Claude Fable 5.2）　**分支：** `fable/arrival-ink`（疊在 `fable/interp-three-halls` 上）
**性質：** 提案＋可走的 preview。未 merge、未動正式站、未碰 ChatGPT plugin。

## 一、選的方向

**灰墨為骨、齊白石式的點色為人氣；全部用程式畫，不用概念圖當素材。**

從 Murphy 的九張圖裡，我取的是：

| 取 | 來自 | 取什麼 |
|---|---|---|
| ✔ | 03 灰墨廟埕、04 八大筆意 | 宣紙底、淡墨染的牆與遠樹、留白的埕、一枝橫過天際的老樹 |
| ✔ | 05 齊白石筆意 | 顏色只點在「人會碰的東西」上：硃砂柱、門、燈籠、柑、紅塑膠凳、麻雀 |
| ✔ | 02 灰墨日常、09 藍線生活 | 茶水桌、電扇、塑膠凳、籃子——有人顧的角落，不是擺設 |
| ✘ | 01 三方向（寫實油畫感） | 太寫實；且三張是三種天氣，不是三種廟 |
| ✘ | 06／07／08 藍線建築 | 精緻、對稱、貴氣——README 已指出不合適；08 的神龕正中軸也違反「中軸不預選」 |

**為什麼不直接用那幾張 PNG：** 它們是單張、未分層、每張的廟都不是同一座；拿來當背景會把門、柱、籤筒焊死，
手機一裁就切到門，三殿也不可能相等。所以這一輪把「同一套筆」做成三支 SVG 濾鏡，整座廟從山門到籤筒都用它畫：

- `#ink-line` 乾筆線（手抖＋墨色濃淡）
- `#ink-wash` 淡墨染（邊緣暈開、濃淡不勻）
- `#ink-rough` 色塊毛邊（硃砂、門扇）

Kimi 的定位（「與不確定性相處的介面」「一本會呼吸的冊子」）我用在氣質上：畫面安靜但不空，問題有案可放。
**籤紙沒有動**（`assets/slip.css`、`assets/slip-render.js` 與 main 相同，測試有鎖）。

## 二、做了什麼（都在 `paper/arrival.html`）

| 段落 | 以前 | 現在 |
|---|---|---|
| 山門 | 淡藍線描底紋 | 兩根硃砂柱、一道簷、一條門檻；入內後埕是「落定」的（520ms），不是切換 |
| 廟埕 | CSS 色塊的牆與殿 | 宣紙、淡墨牆（牆頭是一筆）、牆外遠樹、老樹、近柱是一筆濃墨 |
| 殿面 | 十幾個 CSS 盒子拼的立面，隨視窗拉伸 | **一份墨筆立面**（燕尾脊、出簷、額枋、四柱三開間、窗櫺、台基、階、石獅），三殿共用，**固定 8:9 不拉伸** |
| 轉身選殿 | 同 | 機制不變（先轉正、再進殿）。寬螢幕兩側收進紙的留白，一次只正對一殿 |
| 進殿 | 整個埕放大淡出 | **推門**：正對的那一殿門扇打開、門內的光亮起來，然後才走進去 |
| 殿內 | 聖號牌＋香爐＋籤筒 | 加上樑、柱、神幔、一對燈（會晃、有光暈）、一對燭（火會跳）、兩盤柑；案緣是一筆濃墨 |
| 籤筒 | 白色圓筒 | 竹色的筒、筒裡還有別的籤（按住時輕晃）；抽法不變 |
| 生活 | 牆邊的 CSS 小物 | 前景帶的墨筆小景：長凳、萬年青、麻雀（會跳）、茶水桌＋電扇＋紅塑膠凳＋柑、腳踏車、竹掃帚、水桶、金爐（有煙） |
| 桌機 | 430px 的手機欄置中 | 畫面放寬到 1040px：同一座廟多露牆與埕；文字欄維持閱讀寬度 |
| 手機橫放 | 山門的「入內」被擠出畫面（既有問題） | 門檻自動收緊，可捲動 |

**可動的東西沒有焊在背景上：** 門扇、門內的光、簷下燈籠、殿內的燈與燭火、香煙、樹冠、樹影、麻雀、籤枝、筒裡的籤——
各自成層，由 CSS 驅動；`prefers-reduced-motion` 全部停下。

## 三、保留的規則（測試有鎖）

- **三殿平等**：一份立面模板、一組尺寸（`--hall-w/h` 設在整條站列上）、同一個推門動作；老樹的樹冠最遠只到第一站的簷角邊，不替任何一殿遮蔭。
- **中軸不預選**：boot／reload 一律面向中軸空段；空段中央不放任何小景。
- **先轉正再進殿**：`release` 的 `facedNow` 判準未動。
- **私人的問題與籤簿**：一事一籤、紙落定即入簿、筆記——未動；沒有新增任何對外請求。
- **增建殿 fail-closed**：月老用同一份模板，只剩放樣虛線——無門、無光、無獅、無墨染，也沒有任何抽籤路徑。
- **聲音層**：未動（葉聲的來源位置跟著樹冠的新位置更新了一個數字）。

## 四、考據與界線

建築語彙讀自王保原手稿的立面圖（簷線、柱間、基座、進深）——黃秀蕙〈王保原藝師手稿—廟宇建築剪黏圖面(一)概述〉。
**曲率與比例是 Draw One 自己的 roof grammar hypothesis，不是任何一座真廟的量測或臨摹，也不代表所有台灣宮廟**
（這句寫在模板旁，測試有鎖）。八大山人、齊白石只是筆墨方向的參考（虛實、節制、點色），沒有臨摹任何作品。

`test-arrival-ink-e2e` 的點擊位置由 DOM 算，不寫死座標。

**沒測到（請真機看）**

1. **iPhone Safari 的效能與濾鏡長相。** SVG 濾鏡在 WebKit 的渲染和 Chrome 不完全一樣，轉身時可能掉幀。這是這一輪最大的未知數。若卡：把立面與小景預先轉成點陣圖（同一份 SVG 出圖），互動層不變。
2. **字型。** 沙箱抓不到 Noto Serif TC，我看到的截圖是替代字型；真機的字距、匾的寬度請看一眼。
3. **真機的聲音與觸感**（沒改，但畫面節奏變了，推門 380ms＋走近 560ms 是否太慢／太快，要用手感判）。
4. **深色模式、超寬螢幕（>1600px）、Android 低階機**：未測。
5. **「帶走這支籤」產圖**：流程沒動，但沙箱測不了（同上，字型）。

## 六、我自己不滿意、下一輪想補的

- **筆還不夠像筆。** 現在的線是等寬筆畫加濾鏡，沒有真正的提按與收鋒；殿面的屋頂染得偏灰、偏糊。要更像八大／齊白石，需要手寫的變寬筆路（或請 Murphy 依這份立面的骨架出「可分層」的筆觸素材：脊、簷、柱、門、樹各一層，透明底）。
- **手機上埕面下半部仍偏空。** 前景帶補了生活，但還可以更近身（例如你站的簷下：案、茶杯、籤簿就在手邊——01／03 圖的前景桌是好方向）。
- **石獅只是兩團墨。** 夠寫意，但辨識度低。
- **手機橫放時殿很小**（畫面高度不夠）。可用，但不好看。
- **山門還是文字為主。** 門的「跨」只有落定的那半秒；想做成真的一步（門檻在腳下、埕在門框裡先露一角）。

3. 推門與走近的節奏。

## Round 4（2026-11-14 晚）：筆路 v2——力道在走勢，不在濃淡

回饋來源：Crystal（下筆有力、走勢不軟、上色輕薄；偏好 Murphy v1 的筆觸）、牛牛（結構線清楚、暈染輕；不加物件密度，可少量落葉／掃痕；推門一瞬偏白；匾額裁切、石獅辨識、驗收捷徑可關）、Astra（跨殿原籤掛錯聖號）。

### 判斷

- v1 的線軟，原因不是太淡，而是**等寬筆畫＋抖動濾鏡**：沒有起筆、行筆、收筆。Murphy v1 好看的地方是「一筆有提按、兩頭出鋒、飛白順著筆勢」。
- Murphy 的 PNG 圖層**沒有直接沿用**：它是影像生成的輸出（不透明合成、與 320×360 模板不逐點對齊、只有屋頂與柱、僅桌機 Chromium 試過），放進來會讓門、光、燈這些要動的東西對不上，也多出數百 KB 的點陣圖。沿用的是它的**筆法**。Opuscar 的 Canvas 筆刷（MIT）也只當參考，沒有帶進程式。
- 做法：`INKPEN`——每一筆是由中鋒線取樣、依筆勢（`both` 兩頭出鋒／`press` 頓起提收／`post` 立柱／`flick` 挑）算出寬度的**實心形**；飛白是沿筆勢的 evenodd 細縫（真透明），偏在筆的後段。邊緣只用很小的 `#ink-edge` 位移，保持利。seed 固定，三殿仍是同一份字串（三殿平等不變）。
- 染退後：屋面與牆的墨染降到約 0.2／0.07 以下，只托結構；硃砂柱色薄（.74）而筆實。

### 這一輪動了什麼

| 項目 | 內容 |
|---|---|
| 殿面 | 正脊燕尾一筆到底＋兩挑、簷口一筆、瓦壟、額枋、雀替、台基、階、窗櫺、四柱、門框全部改用 INKPEN |
| 老樹、山門簷、殿內樑柱、供桌、長椅 | 同一支筆 |
| 石獅 | 重畫剪影：頭、鬃、胸、前腿、座，面向門，點睛 |
| 未落成之殿 | 改用 `k-plan` 放樣虛線層（同一份中鋒線），其餘層全關 |
| 推門 | `#threshold`：門內暖光先漫出、殿從光裡定下來，不再露出紙白；reduced motion 與未落成之殿不做 |
| 匾額 | 字級依字數（`--chars`），`max-width: 78%`，不依身分 |
| 掃痕與落葉 | 一處掃痕＋一小堆葉、樹下四片；沒有新增物件種類，中軸中央仍留白（窄螢幕也驗） |
| 供桌 | 電扇移上桌面、桌寬縮，讓出中軸 |

### 沒做／沒測到

- iPhone Safari、Android Chrome、LINE 內建瀏覽器的實機觀感與 SVG 濾鏡效能——沙盒只有桌機 Chromium。
- 真字型（沙盒連不到 Google Fonts）下的匾額字寬。
- 「站姿匾額裁切」：依字數縮放與上限寬度是防守性修正；若牛牛看到的是別的裁切，需要截圖定位。
- 福的乙未／戊午修正（本機分支 `fix/liushijiazi-010-028-ocr`）不在這條分支；本輪沒有碰籤詩資料。

## Round 5（2026-11-14 夜）：驗收後整合

- **殿內聖號被捲出畫面（Astra P2，牛牛重現）**：兩個原因都處理。
  1. 短高規則（`max-height: 720px`）原本排在 `.tube-*`／`.stick` 基礎規則之前，同權重被蓋掉、從未生效；現在移到其後，籤筒 246px、提示上移真的作用。
  2. 走向籤筒的自動捲動保留（籤筒半露會攔截捲頁手勢），但頂列改為 sticky：回埕永遠在；聖號牌一旦被遮或捲出，頂列出現一行完整聖號（同一個字串）。聖號牌不縮、不搬，三殿同一條規則。
  - 回驗（e2e 新增一節）：360×601、390×601、1024×601、1024×768、844×390、390×844——進殿落定後「完整聖號認得出、回埕在畫面內、籤筒整支與提示在畫面內」。
- **硃砂柱遠看稍躁（牛牛）**：飛白減半（dry 1.1→0.6）、硃砂退一階（.74→.64）；筆形不動。
