## 一手來源候選（MUST-TEST）

1. **艋舺龍山寺籤詩簿（實體）**：台灣觀音籤代表性廟宇；需實體取得與翻拍授權。license 查證重點。
2. **華藏淨宗學會《觀音籤·觀世音菩薩感應靈課》**（book.hwadzan.org/books/bfov/）：明代靈課傳統；JS flipbook 無文字層，需抽取頁面圖片或找 PDF 版；法寶通常免費流通（歡迎翻印），授權條款待確認。
3. **東京淺草觀音寺一百籤 PDF（2011 重譯，籤詩網整理）**：已下載 local evidence（sha256 c589742c561c5eb7137b4685b4a162eb69a8e3caed0684bc8a1fa441fb5168fa），**license 未確認不進 repo**；需文字抽取並與 003–006 交叉比對（假說：淺草系或採版本二家族，待驗證）。
4. **數位典藏/古籍掃描**（國圖台灣記憶、中研院、Internet Archive 等）：搜尋「觀音靈課」「觀音感應籤」「籤譜」古本；優先 public domain 掃描。
5. **台灣宮廟自印籤詩簿**（非龍山寺者亦可作獨立一手）：需逐廟授權確認。

## License 查證計畫

- 古本（明清刊本）掃描：目標 public domain（作者歿逾百年），以掃描機構聲明為準。
- 廟方籤詩簿：多為廟方資產；商用需授權，非商業引用須載明來源。
- 網站整理：chance.org.tw 自稱「公版籤詩」但無正式授權聲明 → 一律 unsure，僅作二手佐證。
- 華藏淨宗學會：法寶流通頁通常含授權說明，須實際讀取（MUST-TEST）。

## 判定規則

- 一手來源（掃描/印刷）逐字確認 ＋ 任一獨立來源一致 → 可升級 verified（仍需 license=ok 才能進 draw pool）。
- license=ok 但證據僅 probable → 可顯示於內部，不可進 draw pool。
- 兩者皆過 → draw pool 候選（reference edition 指定後）。

## 本輪不做

- 不大量蒐集、不買書、不付費資料庫。
- 不把網站二手來源當 verified 依據。
