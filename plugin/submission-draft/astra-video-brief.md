# Astra｜一支影片可否兼用

可以評估同片兼用，但活動一分鐘展示與送審所需資訊不同。先交付明天的 60 秒版本；保留原始操作畫面，必要時另剪較完整的審查版本。官方沒有在目前送審說明中指定影片分鐘數，要求展示案例與功能。

建議一分鐘：0–10 秒說明文化文本與自主判斷；10–30 秒真實 ChatGPT 開啟介面、山門入內、廟埕轉身、進殿向上抽籤、取出原版籤紙、顯示原文與核對狀態；30–45 秒收進籤簿、回看同籤、帶走圖片（不含問題與筆記）；45–60 秒說明问题留在介面儲存、無 AI 解籤、目前是私人測試版與公開送審準備中。

送審版本須可核對五正三負案例（見 plugin.json），涵蓋三籤系、同問保留、無保證預測、無自動重抽、無私有資料存取。以實際操作為證；鏡頭展示不得把待複核說成已對勘，也不得把未接入的反思當成現有功能。

不露出真實敏感問題、帳號郵件、身分證件、組織秘密、API key。上傳 accessible URL 後提供給阿福，不須透過其他 agent 自動發訊息。

活动说明：Draw One 是活動前已存在的作品與接入成果，若展示需向主辦如實說明，請求交流展示；不能宣稱現場開始才實作。公開上架尚未完成。
